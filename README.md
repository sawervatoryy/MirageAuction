##  Возможности

| | |
|---|---|
|  **Категории как на FunTime** | Оружие, Броня, Инструменты, Блоки, Еда, Зелья, Ресурсы, Прочее. Категории, иконки, слоты и маски предметов настраиваются в `gui.yml`. |
|  **Два режима продажи** | Фиксированная цена (`/ah sell`) и **торги со ставками** (`/ah bid`) в стиле HolyWorld: стартовая цена, шаг ставки, быстрые ставки, своя ставка через чат, мгновенный выкуп. |
|  **Антиснайпинг** | Ставка в последние секунды продлевает торги (лимит продлений настраивается). |
|  **Поиск** | `/ah search <предмет>` — по материалу, названию, зачарованиям; `@ник` — по продавцу. Кнопка поиска в меню (ввод через чат). |
|  **Гибкий ввод цены** | `100000`, `100k`, `1kk`, `1000000`, `2.5m`, `1.5кк`, `3млн`, `1b` … Суффиксы настраиваются в конфиге. |
|  **Хранилище** | Истёкшие, снятые, выигранные предметы и всё, что не влезло в инвентарь, попадает в личное хранилище `/ah storage`. |
|  **Мои лоты** | Список своих лотов, снятие с продажи в один клик. |
|  **Анимации открытия** | 7 стилей появления: `CASCADE`, `WAVE`, `CENTER`, `SPIRAL`, `RANDOM`, `SNAKE`, `COLUMNS` + «печатающийся» градиентный заголовок + нарастающий звук. |
|  **Цветовые темы** | Основной `&f`, дополнительный `&#FA4249`. 8 готовых тем, свои темы добавляются в конфиг, смена командой `/ah theme` без перезапуска. |
|  **Налог и комиссия** | Налог с продажи, комиссия за выставление, лимиты лотов по правам. |
|  **Живое обновление** | Таймеры и цены в открытых меню обновляются сами. |
|  **Надёжное сохранение** | Асинхронное сохранение `data.yml` (атомарная запись), автосохранение, почта для офлайн-игроков. |

##  Команды

Основная команда `/ah` (алиасы: `/auction`, `/au`).

| Команда | Описание | Право |
|---|---|---|
| `/ah` | Открыть аукцион | `mirageauction.use` |
| `/ah sell <цена> [часы]` | Продать предмет из руки по фиксированной цене | `mirageauction.sell` |
| `/ah bid <старт> [выкуп] [часы]` | Выставить предмет на **торги** со ставками | `mirageauction.bid.sell` |
| `/ah search <предмет>` | Поиск лотов (`@ник` — по продавцу) | `mirageauction.search` |
| `/ah my` | Мои лоты | `mirageauction.use` |
| `/ah storage` | Хранилище | `mirageauction.storage` |
| `/ah help` | Справка | — |
| `/ah reload` | Перезагрузить конфиги | `mirageauction.admin` |
| `/ah theme [имя]` | Список тем / сменить тему | `mirageauction.admin` |
| `/ah remove <id>` | Удалить лот (предмет вернётся продавцу, ставка — участнику) | `mirageauction.admin` |

Русские псевдонимы подкоманд: `продать`, `ставка`/`торги`, `поиск`, `хранилище`, `мои`, `тема`.

### Примеры

```
/ah sell 100000        → лот за 100 000
/ah sell 100k 48       → лот за 100 000 на 48 часов
/ah sell 1kk           → лот за 1 000 000
/ah bid 50k 500k       → торги: старт 50 000, выкуп 500 000
/ah bid 10k            → торги без выкупа
/ah search diamond     → поиск алмазных предметов
/ah search @Steve      → лоты игрока Steve
```

##  Права

| Право | По умолчанию | Описание |
|---|---|---|
| `mirageauction.use` | все | Открывать аукцион, покупать, ставить |
| `mirageauction.sell` | все | Продажа по фикс. цене |
| `mirageauction.bid.sell` | все | Выставление торгов |
| `mirageauction.search` | все | Поиск |
| `mirageauction.storage` | все | Хранилище |
| `mirageauction.admin` | OP | `reload`, `theme`, `remove` |
| `mirageauction.bypass.limit` | OP | Без лимита лотов |
| `mirageauction.limit.<группа>` | — | Лимит лотов группы из `limits.groups` |

##  Управление в меню

**Главное меню:** верхний ряд — категории; 4 ряда лотов; нижний ряд — страницы, сортировка, тип лотов, мои лоты, информация/баланс, хранилище, поиск, обновление.

| Действие | Результат |
|---|---|
| ЛКМ по лоту (фикс. цена) | Окно подтверждения покупки |
| ЛКМ по лоту (торги) | Меню торгов: быстрые ставки, своя ставка, выкуп |
| ПКМ / Shift по своему лоту | Снять с продажи |
| ПКМ по «Сортировка / Тип» | Предыдущее значение |
| ПКМ по «Поиск» | Сбросить поиск |
| Клик по предмету в хранилище | Забрать предмет |

### Как работают торги
- Ставка списывается с игрока сразу и хранится «в залоге».
- Если ставку перебили — деньги автоматически возвращаются прежнему лидеру.
- Минимальный шаг: `max(min-step-flat, ставка × min-step-percent%)`.
- Если сумма ставки ≥ цены выкупа — лот выкупается мгновенно.
- По окончании времени лот достаётся лидеру, продавец получает сумму за вычетом налога. Нет ставок — предмет возвращается продавцу в хранилище.
- Антиснайпинг: ставка за `window-seconds` до конца продлевает торги на `extend-seconds`.

## ⚙ Конфигурация

Все файлы лежат в `plugins/MirageAuction/`.

### `config.yml`
| Раздел | Что настраивается |
|---|---|
| `theme`, `themes` | Активная тема и список тем (цвета, градиент, стёкла) |
| `economy` | Провайдер (`VAULT` / `PLAYERPOINTS`), налог, комиссия |
| `limits` | Мин./макс. цена, лимит лотов, группы лимитов |
| `duration` | Длительность лотов (по умолчанию / максимум) для продажи и торгов |
| `bid` | Шаг ставки, быстрые ставки, антиснайпинг, снятие лота со ставками |
| `blacklist` | Запрещённые материалы, слова в названии и лоре |
| `delivery`, `broadcast` | Доставка в инвентарь, объявления о новых лотах |
| `format` | Стиль цен (`FULL`/`SHORT`), символ валюты, суффиксы ввода (`k`, `kk`, `м`, `млн` …), единицы времени |
| `animation` | Стиль и скорость анимаций, печатающийся заголовок, тон звука |
| `gui` | Антиспам кликов, автообновление, сортировка по умолчанию |
| `storage` | Автосохранение, период проверки истёкших лотов |
| `sounds` | Все звуки в формате `ключ;громкость;тон` |

### `messages.yml`
Все сообщения чата. Поддерживаются `&`-цвета, `&#RRGGBB`, `<gradient:#A:#B>текст</gradient>` и плейсхолдеры темы.

### `gui.yml`
Заголовки и кнопки всех меню (материал, название, лор, слот, свечение), категории и маски предметов, лор лотов, причины в хранилище.
Слоты задаются числами или диапазонами `"9-44"`. Строки лора с пустым плейсхолдером (например `{buyout}`) скрываются автоматически.

##  Цветовые темы и адаптация

Любой текст в конфигах понимает:

| Формат | Пример |
|---|---|
| Классические коды | `&f`, `&7`, `&l` |
| HEX | `&#FA4249` |
| Градиент | `<gradient:#FA4249:#C80000>Текст</gradient>` |
| Плейсхолдеры темы | `{primary}` `{secondary}` `{accent}` `{dark}` `{success}` `{error}` |
| Градиент темы | `{grad:ТЕКСТ}`, `{gradb:ТЕКСТ}` (жирный) |

Стандартная тема `mirage`: основной `&f`, дополнительный `&#FA4249` (градиент `#FA4249 → #C80000`).
Готовые темы: `mirage`, `purple`, `pastel`, `ocean`, `gold`, `emerald`, `sakura`, `mono`.

Своя тема — просто новый блок в `themes:`:

```yaml
themes:
  mytheme:
    primary: "&f"
    secondary: "&7"
    accent: "&#FFAA00"
    dark: "&#CC7700"
    success: "&a"
    error: "&c"
    gradient: ["#FFAA00", "#CC7700"]
    pane-accent: ORANGE_STAINED_GLASS_PANE
    filler: BLACK_STAINED_GLASS_PANE
```

Затем `/ah theme mytheme`. Любая дополнительная строка темы (например `warn`) становится плейсхолдером `{warn}`.

##  Анимации

```yaml
animation:
  enabled: true
  open:
    style: WAVE      # CASCADE | WAVE | CENTER | SPIRAL | RANDOM | SNAKE | COLUMNS
    step-ticks: 1    # период шага
    per-step: 3      # слотов за шаг
  title:
    enabled: true
    text: "AUCTION"  # печатается градиентом темы
```

При открытии предметы появляются по выбранному шаблону под нарастающий звук, заголовок «печатается» градиентом активной темы. Смена категории — быстрая каскадная анимация (`animation.switch`).

##  Данные

Лоты, хранилище и почта офлайн-игроков — в `plugins/MirageAuction/data.yml`. Предметы сохраняются в бинарном формате Paper (NBT, компоненты 1.21 сохраняются полностью). Запись атомарная, не блокирует сервер.

##  FAQ

**Нет экономики / «Экономика недоступна».** Установите Vault и экономический плагин либо укажите `economy.provider: PLAYERPOINTS`.

**Как изменить размер страницы?** `gui.yml → main.lot-slots`.

**Как добавить категорию?** Новый блок в `gui.yml → categories` со своим `slot`, `material` и масками `match`.

**Работает на Spigot?** Нет, только Paper 1.21.4+.
